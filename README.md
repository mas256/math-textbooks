# Equashare Web v5.0.2

このRepositoryのGitHub PagesはEquashareのブラウザー版を配信します。

- 公開サイト: https://mas256.github.io/math-textbooks/
- ソースとWindows版・拡張機能版のRelease: https://github.com/mas256/Equashare
- 静的サイトの内容: Equashare Chrome/Edge版のビルド成果物

`main`へのPushでPagesを自動デプロイします。拡張機能版のソースはEquashare Repositoryの`extension/`にあります。
