## 作成方針

各IDに問題文と解答を固定する。出題時に係数・初期値を変更する自動生成は行わない。$M$ や $x,y$ を含む問題も、その条件のまま出題する一つの固定問題である。問題の選択・順序の抽選は、問題内容の生成と別に実装できる。

一般項を求める問題に加え、収束・最小周期・整数性・床関数や桁の意味を問う問題を含めた。ニュートン法の立方根、初項依存の収束、高階や変則添字の増大評価では、閉じた一般項を要求しないことを明記した。添字が0から始まる問題には $a_0$、三階の問題には三つ、五階の問題には五つの初期値を記した。二重数列には境界条件を記した。

## データと確認方法

編集元は `level6.json`。`statement`、`hint`、`answer`、`solution` が学習用の本文、`source` が出典、`verification` が検算用の式と範囲である。解説の数学的帰納法・不変量・不等式などで全添字に対する論証を記し、別途SymPyによる有理数・代数的数・三角関数の厳密な有限項の検算と恒等式検査を行う。浮動小数点の許容誤差による判定は用いない。

二重数列は境界と内側の更新、連立は両方の数列と保存量、母関数は有限次数までの係数、畳み込みは有限和も検算する。パラメーター問題には境界値・定数解などを含む検算用の値を記録する。変則添字の問題は初項からの直接計算で増大の下界を照合する。パラメーターの全範囲や極限の論証は解説に記し、有限検算と区別する。

Repositoryルートから実行する。

```bash
python3 recurrence/scripts/authored_workbook.py
python3 recurrence/tests/level6_check.py
python3 recurrence/scripts/authored_workbook.py --check
```

`authored_workbook.py` は固定データをMarkdownに整形するだけで、問題や数値を生成しない。編集後は問題集と解説を再出力する。`--check` はJSONと文書の一致を確認する。検算にはSymPyが必要。

## 今回の範囲

難易度6を選んで1問ずつ出題でき、分野での絞り込みにも対応する。「まとめて出題」ではこの60問から2問を抽選し、Lv1〜5の12問と合わせて表示する。どちらもヒント・解答・印刷・TeX出力とリンク共有に対応する。既存のLv1〜5公開バンクとは別のデータ形式で、現在の生成スコアから難易度を計算していない。

この60問はLean未検証である。有限項の厳密計算や解説の論証を、既存バンクの `lean-verified` として扱わない。配信時は `data/level6.json` に別ファイルとして配置し、画面の「この問題生成について」に検証の範囲を明記する。生成問題の検証済みバンクとマニフェストは変更しない。
