# 漸化式問題ジェネレーター

公開サイトの通常入口 `/recurrence/` は、[recurrence-equation-generator](https://github.com/mas256/recurrence-equation-generator) v0.4.0のブラウザー版を使用します。42系統・123細分類から、Lv1〜5の問題をその場で生成します。通常演習、解法選択、別解演習、独立したヒントと別解、TeX出力、Recipeの保存・再現、履歴に基づく出題配分に対応します。未対応の分野は画面の「生成範囲」で確認できます。

エンジンの取得元・完全なコミットSHA・版を `engine-lock.json` で固定します。公開処理ではそのコミットのビルド済みブラウザー資産を変更せずに取得し、公開資産のSHA-256を照合します。配信先は `engine/<コミットSHA>/` で、各ファイルのハッシュと取得元を同じ場所の `provenance.json` に記録します。入口HTMLのメタ情報にはエンジンとサイト双方のコミットを残します。上流へのマージだけでは自動更新せず、このロックを更新したPRの検証・公開を経て反映します。

**動的生成の検査はLeanによる全項証明ではありません。** 通常型は初期条件・漸化式・定義域を有限項で厳密に検査し、項が急増する対数型では小さい項の厳密計算、指数の恒等式、剰余検査を併用します。別解の検査範囲も画面に表示します。難易度は登録解法に基づく教育上の設計値で、学習者の実測による校正は今後の課題です。

`textbook.html` では既存の教材問題、Lv6固定問題、14問セット、リンク共有、印刷、Equashareを利用できます。既に公開した `?problem=L6-N03` などの問題リンクと `?batch=...` のまとめ問題リンクは、IDと順序を変えずに教材画面へ引き継ぎます。動的生成した問題の再現にはRecipeを保存してください。画面間には移動リンクがあります。

## 動的生成エンジンの準備と更新

Python 3.11以上を使います。`engine-lock.json` に記録されたコミットをチェックアウトした上流リポジトリを指定します。

```bash
git clone https://github.com/mas256/recurrence-equation-generator.git /tmp/recurrence-engine
git -C /tmp/recurrence-engine checkout 9788b5d95653a8be91759be9e48be31aad2db7dc
python3 recurrence/scripts/prepare-lab.py --engine-root /tmp/recurrence-engine
```

版を更新するときはロックのSHAと版を変更し、対応する上流コミットをチェックアウトして、上の準備コマンドに `--write-entry` を付けて入口HTMLを更新します。CIはコミット・版・入口HTMLの一致を検査し、改変した上流の配布資産を拒否します。`engine/` はビルド成果物でありコミットしません。公開処理では教材バンクの検証後、`assemble-site.py` でサイトを組み立て、その成果物でも演習と旧URLを検査してから公開します。

Pagesの公開後も、実際の公開URLに対して同じブラウザー検査を実行します。HTMLのサイトコミットが公開対象と一致すること、配信資産のハッシュ、動的生成、3モード、Recipe再現、既存のLv6リンクを確認します。公開直後の配信遅延に備えて最大3回試し、確認できなければ実行を失敗として報告します。

以下は `textbook.html` で提供する従来の教材バンクの仕様です。教材側の分類と生成規則を、動的エンジンの分類・対応範囲と混同しないでください。

## 教材バンク

高校数学の漸化式を、保存した生成規則から出題する静的な教材バンクです。教材バンクv0.8.0では31系統・278問を生成します。教材側の生成問題は、一般項、初期値、漸化式、一意性をLeanで検証できたものだけを公開します。

難易度6向けに、未生成分野の[固定問題60問](authored/level6-problems.md)と[方針・解答・解説](authored/level6-solutions.md)を事前作成しました。ガウス型・隣接4項間・ニュートン法・対称式・三角関数・非隣接型に加え、二重数列・母関数・畳み込み・ペル方程式などを扱います。「まとめて出題」から固定問題を選び、係数・初期値・小問は変更せずに表示します。データ形式と検算範囲は[固定問題集のREADME](authored/README.md)に記しています。固定問題は生成問題のLean検証済みバンクとは別に配信します。

## 画面とTeX出力

難易度1〜6から選び、ボタンで1問ずつ出題します。Lv6は固定問題60問を分野でも絞り込め、各問のリンク共有・ヒント・解答・印刷・TeX出力に対応します。生成問題の検証情報と、固定問題の出典・検算情報は別の折りたたみに表示します。ヒントは主解法の方針を表示し、解答は置換・式変形・初期条件・一般項の順に教科書調の文体で示します。解法選択のスコア比較は検証情報の折りたたみにまとめます。

「まとめて出題」はフィルターにかかわらず、Lv1・2・5・6を各2問、Lv3・4を各3問、計14問を難易度順に表示します。まとめ問題専用にレベル別の出題履歴を持ち、一巡するまで既出を除外し、巡回の境目でも同じ14問の中では重複させません。各問の直下に「ヒント」「答え」「Equashare」「TeX」を並べ、ヒントと答えはその問だけを独立して開閉できます。TeXは押した問題だけを保存し、その問題の答えを開いていれば解答も含めます。印刷とリンク共有は14問全体が対象で、リンクから同じ問題と順番を復元できます。1問の演習には「1問出題」で戻ります。

TeXは教科書と同じjsbook・A4・11pt・20mm余白・2段組（段間12pt、罫線0.4pt）です。pLaTeXとdvipdfmxで組版します。解答を開いているときは「方針・解答・解法」と別解を含み、閉じているときは問題のみを出力します。長い数式は段幅に収めます。

各問の「Equashare」は、その問題を入力済みのブラウザー版Equashareを新しいタブで開きます。問題文は `\text{…}`、初期条件・漸化式・総和の定義などは1行1数式で渡し、文書設定や数式の区切り記号は付けません。解答を表示している場合も、渡すのは問題だけです。

Equashare連携は1問出題・まとめて出題の両方で使え、難易度6の添字の範囲と小問もそのまま渡します。

## 難易度と出題頻度

| レベル | 分類の目安 |
| --- | --- |
| Lv1 | 等差・等比、基本的な階差の和 |
| Lv2 | 基本的な総和の消去、単項式の積による階比、倍率が一致する指数付加項 |
| Lv3 | 基本的な連立、単項式以外の通常の階比、基本的な3項間、対数基本型、指数付加項 |
| Lv4 | シンプルな一次分数、定数項を含む3項間、少し難しい階比、等差と階差の組合せ、平行移動した対数型 |
| Lv5 | 正規化・総和・階差・対数・特解などを複数組み合わせる発展問題 |
| Lv6 | 事前作成した固定問題：ガウス型・隣接4項間・非隣接型・ニュートン法・対称式・三角関数・二重数列など |

基本形の総和はLv2、連立はLv3です。さらに正規化や一次式の特解などが必要な総和・連立には上位レベルを割り当てます。従来の難しいLv4の複合問題はLv5へ移しました。

一次分数は `(p a_n+q)/(r a_n+s)` の形を24問追加しました。総積の階比は `r n`、`r n²`、`r(n+1)`、`r n(n+1)` など21問を追加し、階乗まで評価した一般項を表示します。定数項付き3項間は12問、等差と階差の組合せは8問です。

v0.8.0では、教科書の基礎的な不足を補う3系統を各12問追加しました。数値を変えた候補から選題する生成規則であり、難易度6の固定問題とは別です。

| 系統 | 生成する基本形 | 主解法 | 難易度 |
| --- | --- | --- | --- |
| 対数基本型 | $a_{n+1}=C a_n^q$ | 正値を確認し、対数をとって一次の漸化式にする | Lv3 |
| 平行移動した対数型 | $a_{n+1}=h+C(a_n-h)^q$（出題時は展開） | 平方完成・因数分解で $a_n-h$ を見つけてから対数をとる | Lv4 |
| 指数付加項 | $a_{n+1}=p a_n+c r^{n-1}$ | $r^{n-1}$ で割り、等差または定数項付き一次型にする | $p=r$ はLv2、その他はLv3 |

対数型の指数は2・3、係数 $C$ は1・2・3、平行移動 $h$ は $\pm1$、対数をとる量の初項は正の登録値です。指数付加項は $p,r\in\{2,3,4\}$ で、倍率が一致する場合・異なる場合を各6問選びます。一般項に未評価の等比の和は残しません。初項と係数だけから解法を再検出し、生成時の一般項は参照しません。

抽選は未出題の系統を選んでから数値の異なる問題を選びます。`selection.family_weights.mobius=2` により一次分数の新しい系統は通常の系統の2倍の重みで選びます。レベル・系統の絞り込みと既出問題の除外を先に適用するため、実際の確率は候補の構成で変わります。同じ候補を一巡するまで問題IDは重複しません。

## 生成と採点

`Recipe → 統合・制限 → ProblemIR → 係数からの解法検出 → 構造の選別 → TeX / Lean / 厳密計算 → Lean検証 → 公開バンク`

すべての数学的出力は同じ式ASTを用います。前向きの解法検出は生成時の一般項を使用せず、係数と初期値から登録した解法を探します。正規化、多項式の特解、特性方程式、連立の分離、総和の消去、階差、一次分数の不動点、総積と階乗、対数基本型、平行移動した累乗、指数付加項を認識します。任意の漸化式を解く探索ではありません。

操作B・発見R・計算A・条件確認T・式の複雑さP・未評価Uの合計は監査用に残します。教育上の難易度は構造別の分類で調整し、元のB+R+T、調整量、理由を各解法に保存します。初期値の大きさやTeXの長さでレベルが変わることを避けます。主解法は教育上の難易度、合計、数値コスト、解法名の順で選びます。

難易度スコアの区間はLv1=0–3、Lv2=4–7、Lv3=8–12、Lv4=13–18、Lv5=19–25です。構造別の値と分類理由は `scripts/scoring.py` にあります。配点は学習者による実測で較正した値ではありません。

## 生成規則と選題

`generation-config.json` が変形回数、登録関数、出題数、採用上限、抽選の重みを管理します。連続した定数付加・定数倍は統合し、恒等変形を取り除きます。基本的に同種の変形は1回、付加ブロックは最大4回です。差を足して戻す操作は2回までです。制約で必要数を生成できなければ生成を失敗させます。

正規化関数は `n, n+1, n², n(n+1), n(n+2), 2n+1` と各逆数です。指数係数の指数は `n, 2n+1, n(n+1)/2`、総積の因子は `n, n+1, n+2` の登録組合せです。

採用条件は係数次数2、問題のAST要素数44、分数の深さ2、加算構造8、発見コスト3、数値コスト8までです。定数だけの数列、未完結の解法、未評価の和・積は出題しません。Lv3〜5では逆数以外の系統を各3種類以上、逆数型を各40%以下にします。採用候補の数値・係数・登録関数の分布も均衡させます。

`reference/public-problem-ids.json` は公開した問題の初期値と漸化式の指紋を保持します。数学的に同じ問題だけIDを引き継ぎ、廃止IDは再使用しません。レベル変更でIDは変わりません。新しい問題を開発時に登録し、台帳をコミットします。

## 検証

Lean 4.19.0とmathlib v4.19.0を固定します。全問で一般項の初期値、全自然数添字での漸化式と一意性を証明します。一次分数では元の分母と逆数置換の分母の非零性も証明します。学校の添字1はLean内部の0です。連立は両方の数列、総和は最初の境界と有限和を検証します。

通常の254問は各24項、新しい対数型24問は各8項の厳密計算を行い、合計6,288件の漸化式を検算します。対数型は項が急増するため、大きな整数をそのまま24項計算する代わりに、さらに3つの素数を法として各24項を元の更新から独立に計算し、一般項と照合します（1,728件）。この剰余検査は回帰検査であり、全添字の証明の代わりにはしません。

置換後の式、Recipe再生、生成履歴を隠した解法検出、難易度方針、既存ID、重み付き抽選も検査します。対数をとる量の全添字での正値性、一般項の自然数指数、表示用の等比の和の閉じた式もLeanの証明対象です。CIではMathJaxですべての問題・解答・解法を描画し、各系統の長い解答とLv5の操作をスマートフォン幅でも確認します。

`certify.py` はコンパイル結果、公理依存、証明ソースのハッシュ、台帳、採用条件を監査します。未完成の証明や仮定した独自公理を含む結果は公開しません。画面は問題バンクと検証マニフェストを照合します。日本語の解説文や学習上の難しさそのものはLeanの検証対象ではありません。

## 開発

```bash
python3 recurrence/scripts/generate.py --update-id-registry
python3 recurrence/tests/math_check.py
python3 recurrence/tests/elementary_check.py
python3 -m pip install -r recurrence/requirements-dev.txt
python3 recurrence/scripts/authored_workbook.py --check
python3 recurrence/tests/level6_check.py
node --test recurrence/tests/model.test.mjs recurrence/tests/elementary-model.test.mjs recurrence/tests/batch-model.test.mjs
cd recurrence/lean
lake exe cache get
lake build 2>&1 | tee ../build/lean.log
cd ../..
python3 recurrence/scripts/certify.py
```

通常の生成では `--update-id-registry` を付けず、未登録の選題を拒否します。Pagesは同じコミットの生成・Lean検証・ブラウザー検査を通った成果物で公開します。

`tests/elementary-browser.cjs` は外部通信を使わず、新規36問の選択・重複回避・ヒント・解答・TeXダウンロードを確認する補助検査です。認証メタデータとMathJaxはメモリ上のテスト用代替物で、検証済みバンクを書き出しません。Lean検証や数式の組版検査には、通常の公開前検証を使います。

教科書体裁の演習集は `workbook.py` で5レベル各15問を選び、`typeset_workbook.py` でjsbook・A4・11pt・20mm余白・2段組のTeXにします。
