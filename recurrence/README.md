# 漸化式の問題生成 v0.1.0

公開先：<https://mas256.github.io/math-textbooks/recurrence/>

設計v0.2に基づく初版です。GitHub Actionsで50問を作成し、Leanの検証に成功した問題だけをGitHub Pagesに配信します。ブラウザーは難易度・型の条件を満たす問題を選びます。各問題のリンクで同じ一問を共有できます。

## データの流れ

`ブロックRecipe → compile_blocks → ProblemIR → TeX / Lean / 厳密計算 → Lean検証 → 問題バンク → MathJax`

- Recipeは値域・添字・核・各ブロックの入力と出力・有理数パラメータを保存します。
- `scripts/compiler.py` がレシピを再生します。画面の数式とLeanの検証対象は同じ式ASTから出力します。
- 初期値は一般項から厳密な分数として決定します。パラメータ候補は乱数シードを固定して探索し、扱いやすい数値を優先します。
- 生成履歴と表示する主解法は別です。実装済みの完結した解法のコストを比較し、最小のものを主解法にします。
- 問題だけを表示しているときのTeX保存・印刷には解答を含めません。解答を表示した後には解答も含めます。

## 初版の対応範囲

10系統、各5問、合計50問です。

| 系統 | 暫定コスト | 難易度 |
| --- | ---: | --- |
| 定数数列 | 1 | 1 |
| 等比数列 | 2 | 1 |
| 特性方程式型（2項間、不動点） | 5 | 2 |
| 階比型、正規化で定数になるもの | 4 | 2 |
| 階比型＋定数の移動 | 7 | 2 |
| 階比型＋特性方程式型 | 9 | 3 |
| 3項間、異なる実数根 | 6 | 2 |
| 指数係数の階比型 | 4 | 2 |
| 逆数型＋特性方程式型 | 9 | 3 |
| 逆数型＋階比型＋特性方程式型 | 15 | 4 |

ここで「特性方程式型」は、不動点を引いて等比数列にする2項間の型です。3項間の特性多項式と区別しています。

## 検証と公開の条件

Lean 4.19.0とmathlib v4.19.0を固定しています。`lean/lake-manifest.json` は推移的な依存関係のコミットも固定します。

各問題について初期値と一般項の一致、すべての自然数添字での漸化式、一意性を証明します。逆数型は、生成される数列の正値性、各項が0でないこと、次の項を作る分母が0でないことも全項で証明します。表示上の最初の添字は1、Lean内部では0です。値域は有理数です。

`certify.py` はコンパイル済みの定理、生成ソースのハッシュ、各定理の公理依存監査を確認します。`sorry`・`admit`・独自の `axiom` や `sorryAx` を含む結果は公開しません。通常のLeanの基礎公理は使用します。有限項の厳密計算はバグ検出用であり、Leanの全項での証明とは分けています。

日本語の解答と別解の文章は表示用のテンプレートです。文章の各行や対数を使う別解そのものを独立したLean定理として検証する段階には達していません。問題の一般項とその一意性は検証対象です。

Pagesは同じコミットの生成・Lean検証・ブラウザー確認に成功した成果物を使います。検証失敗時はデプロイを止めます。画面側も問題バンクのSHA-256を検証マニフェストと照合し、不一致を出題しません。

## スコア

主解法コスト `C = B + R + A + T + P + U` を使います。Bは操作、Rは発見、Aは計算、Tは条件の確認、Pは中間式の負担、Uは未評価の和・積です。初版ではルートごとのB・R・Tを登録し、A・Pは簡単な候補を選ぶことで0に制限します。完成した通常問題のUは0です。

主なB：定数1、等比2、不動点を引く2、定数の移動2、nで正規化3、逆数3、異なる実数根の3項間5、比を積にする2、積の評価1、対数3、差を和にする2、和の評価1。Rは明示的な基本形0、チャートの一つの手がかり1、複数の性質の関係2。逆数型のTは正値性による条件確認1です。

難易度区間：Lv1は0–3、Lv2は4–7、Lv3は8–12、Lv4は13–18。Lv5の19–25に対応する問題は初版にはないため、画面には選択肢を置いていません。これらは暫定値で、学習者による測定は未実施です。

数値の扱いやすさは `scripts/scoring.py` に定義しています。既約分数にして、好ましい分子 `{0,1,2,3,4,5,6,8,9,16,25}`、分母 `{1,2,3,5,8,9}` を優先します。平方数と2・3・5の累乗にも軽減を与えます。教育的品質Qの自動推定は参考値であり、人間による良問の認定には使いません。

## 開発

```bash
python3 recurrence/scripts/generate.py
python3 recurrence/tests/math_check.py
node --test recurrence/tests/model.test.mjs
cd recurrence/lean
lake exe cache get
lake build 2>&1 | tee ../build/lean.log
cd ../..
python3 recurrence/scripts/certify.py
mkdir -p recurrence/data
cp recurrence/build/problems.json recurrence/build/manifest.json recurrence/data/
python3 -m http.server 8787
```

Leanの証明をダウンロードした場合は、このリポジトリの `recurrence/lean` をLakeプロジェクトとして使ってください。証明は `Recurrence.Theory` に依存します。

## 現在の制約と次の拡張

- 自由な係数やブロックをブラウザーで編集する機能はありません。型付きの登録済みブロック列からビルド時に生成します。
- 主解法の比較は登録済みのルート内です。任意の式からすべての解法を探索するソルバーは未実装です。
- nに応じた倍率は `n(n+2)` と三角数指数のプロファイルに限定しています。一般の階乗・複数因子の積へ拡張できます。
- 一般の一次分数型、重解・複素根、対数型を核へ変形する構成、差分・部分和による次数の引き上げは今後の対象です。
- 同一問題の重複は式ASTと初期値で除いています。任意の代数的同値性を判定するものではありません。
- 解答の各行を形式化すること、式の形と途中計算からA・Pを算出すること、学習者の正答率で難易度を較正することが次の主要課題です。
- MathJax 4.0.0はCDNから読み込みます。読み込みに失敗した場合は数式の元のTeXと再読み込みボタンを表示します。
