# 漸化式の問題生成 v0.3.0

公開先：<https://mas256.github.io/math-textbooks/recurrence/>

70問・12系統の調整版です。ブロックRecipeを生成し、完成式を評価してから、Leanの検証に成功した問題をGitHub Pagesに配信します。ブラウザーは難易度・型に合う検証済みの一問を選びます。係数やブロックを画面で自由に編集する機能はまだありません。

## 今回の変更

- 解答冒頭で着眼点と主解法の選択理由を表示し、別解では各スコア項目の増減を比較します。合計が同点なら未丸めの数値コスト、さらに同点なら解法名で並べます。同点の表示順は数学的な優劣を意味しません。TeX出力にも同じ情報を含めます。
- 同じ種類の付加ブロックの上限を設定しました。係数を変えても同じ種類として数えます。
- 正規化用の関数と指数の和用の関数を分けて登録しました。任意の多項式は採用しません。
- 生成履歴を使わず、完成した漸化式の係数と初期値から対応済みの解法を検出します。
- 係数の次数、式の要素数、分数の深さ、途中で求める数値を評価します。旧版のA・Pの固定0と種類別の固定品質点を廃止しました。
- 逆数を取ると `v(n+1)=r v(n)+c(r-1)n` になる、短い発展問題を追加しました。
- 同じ関数の変形だけでなく、係数の異なる問題も選びます。数値コストが同じ候補では、未選択の係数パターンと、公比・指数の底の分布を優先します。
- 数値と数値べきの積には乗算記号を付け、加算式を総和に入れる際は括弧を付けます。三角数・四面体数は表示時に積・分数の形にします。
- 一次式の特解の係数比較、3項間の初期値の連立方程式、逆数型の正値性と分母の確認を解答に加えました。置換後の初期値と漸化式も式ASTに記録します。
- 公開済みの全問題のIDを `reference/public-problem-ids.json` に保存します。漸化式と初期値が一致する場合に限って引き継ぎ、削除した問題のIDは再使用しません。

## データの流れ

`Recipe → 統合・回数制限・関数制限 → ProblemIR → 前向きの解法検出 → 完成式の選別 → TeX / Lean / 厳密計算 → Lean検証 → 問題バンク → MathJax`

`scripts/compiler.py` が保存したブロック列を再生します。数式、一般項、Lean証明の数学的な入力は同じ式ASTです。初期値は一般項から厳密な分数で求め、表示する係数・初期値・置換後の初期値・不動点・特解の係数の扱いやすさで数値候補を選びます。

## 回数制限

`generation-config.json` で変更できます。既定値は各種類1回、核を除いた付加ブロック全体で3回です。

| 付加ブロック | 上限 |
| --- | ---: |
| 定数付加、定数倍 | 各1 |
| nに応じた倍率、nの一次式の付加 | 各1 |
| 逆数、等比数列の組合せ | 各1 |

連続する定数付加・定数倍は統合し、恒等変形を除いてから数えます。離れた位置の同種ブロックは別々に数えます。連続する逆数は不要な候補として除外し、途中の定義域の確認を消して採用することはしません。核に含まれる不動点の操作などは、解法コストでも評価します。総和・差分・連立ブロックは未実装です。

上限を厳しくして既定の出題数を作れなくなった場合は、生成を失敗させます。自動で制約を緩めません。対象の系統の `quotas` も調整してください。

## 用途別の関数

正規化用の関数gは `n, n+1, n², n(n+1), n(n+2), 2n+1` と各逆数です。階比の倍率には、その隣接比 `g(n+1)/g(n)` を使います。定数rを組み合わせる構成もあります。共通の多項式因子は約分してから表示・採点します。例えば `n(n+1)` の隣接比は `(n+2)/n` になります。

| 指数係数の指数f(n) | 累積指数h(n) |
| --- | --- |
| n | n(n−1)/2 |
| 2n+1 | (n−1)(n+1) |
| n(n+1)/2 | (n−1)n(n+1)/6 |

指数係数は `a(n+1)=r^f(n) a(n)` という形式です。`a(n+1)=a(n)^f(n)` という実数べきの型は未実装です。関数カタログの用途情報には、将来の対数後の総積に使える性質も保存します。倍率に多項式を直接入れて階乗を生む系統も、現在の出題には含めません。

## 完成式の採用条件

既定値は、多項式係数の最高次数2、問題の漸化式のAST要素数44、分数の深さ2、加算構造の項数指標8までです。指数係数は登録した指数の族で制限します。対応済みの完結した解法があり、発見コスト3以下、数値コスト8以下、Lv1–4に入ることも必要です。逆数の後に非自明な定数移動と正規化と不動点の操作をすべて隠した候補も除外します。

要素数は、漸化式の左右にある演算・係数・添字・数列の項をASTで数えた値です。字数や読者の認知負荷そのものではありません。品質点は `max(0,30−2P−R−A)` の参考値であり、採用条件と分けています。

`scripts/solve.py` は係数と初期値だけを読みます。登録したgに対する正規化、定数移動、一次式の特解、特性多項式の異なる有理数根、登録した指数の和を認識します。正規化と特解は、多項式の恒等式を厳密に確認してから解法候補にします。全ての数学的な別解を探索するものではありません。

## スコア

主解法は `C=B+R+A+T+P+U` が最小の完結した候補です。

- B：定数1、等比2、不動点2、定数移動2、正規化3、逆数3、一次式の特解4、異なる根の3項間5、総積2＋評価1、対数3＋総和2＋評価1。
- R：係数・付加項から検出した正規化、定数移動、不動点の各1。一次式の特解2。逆数を経由する候補には1を追加します。
- A：表示する数値と途中で求める数値のコストの和、上限6。好ましい分子 `{0,1,2,3,4,5,6,8,9,16,25}`、分母 `{1,2,3,5,8,9}` を優先します。採用された問題のAが0になることはあります。
- T：逆数や対数の条件確認1。
- P：問題と置換後の一般項を測ります。要素数18を超えた分を10ごとに1、係数の次数・指数の次数・分数の深さの1を超えた分も加え、上限6とします。
- U：未評価の和・積。通常の出題では0が必要です。

Lv1は0–3、Lv2は4–7、Lv3は8–12、Lv4は13–18です。学習者による較正は未実施です。スコアの低さだけで選ばず、登録した関数と係数の多様性も確保します。

## 調整前後の検証

旧50問を `reference/quality-baseline.json` に保存しています。同じ測定方法で比較すると、係数の最高次数は4から2、漸化式の要素数の最大値は41から20、平均は13.60から9.61になりました。旧50問のうち10問は新しい条件を満たしません。候補2054件のうち1646件が構造上の条件を満たし、その中から70問を出題用に選んでいます。

候補の規則違反・不採用理由・代表例は `build/quality-report.json` に記録します。公開ページの「作問ルールと今回の比較」から確認・保存できます。問題数と系統の構成が異なる比較であり、人間による良問性の改善を証明する結果ではありません。

前版の70問は `reference/quality-v0.2.json` に保存しています。同じ70問での再選題では、初期値の違いを除いた係数パターンが58から61に増えました。階比型＋特性方程式型は公比2が6問から、公比2・3が各3問になりました。指数係数も底2・3が各3問です。難易度別の問題数、係数の最高次数2、式の要素数の最大20・平均9.61を維持しています。

選題は登録関数のグループを一巡してから数値違いを選びます。同じ数値コストでは、係数の重複、公比・指数の底の出現数、式のコスト、解法コストを比較し、最後の同点では既存の問題を優先します。定数数列など、係数パターンが少ない型には初期値違いも含めます。この分布の均衡も暫定的な選題方針です。

公開IDは、初期値と、共通因子・全体の定数倍を取り除いた係数の情報をハッシュ化して対応付けます。新しい問題には履歴の最大値より後の番号を割り当てます。通常の生成と公開処理では未登録の問題を拒否します。新しい選題を開発時に登録して、台帳をソースと一緒にコミットしてください。

## 正しさの検証

Lean 4.19.0とmathlib v4.19.0を固定しています。全70問で初期値、すべての自然数添字での漸化式、一般項の一意性を証明します。逆数型は全項で正値性・各項の非零性・次の項を作る分母の非零性も証明します。一次式の付加項を使う逆数型の正値性は、正の初項と漸化式から帰納法で証明します。学校の最初の添字1はLean内部の0に対応します。

1680ケースの厳密な有理数計算、Recipeの再生、生成履歴なしでの解法検出、制限変更、旧例の不採用、全登録関数の積・和、全履歴のID維持、全問題・解答・別解のMathJax描画、各系統の長い解答のスマートフォン表示も確認します。置換後の初期値と漸化式も24項ずつ検算し、最終一般項が正しくても中間関係が誤っていれば拒否します。有限項の計算はLeanの全項での証明と別の検査です。

`certify.py` は実際のLeanコンパイル、公理依存監査、生成ソースのハッシュ、Recipeの再生と採用条件を確認します。`sorry`、`admit`、独自の `axiom`、`sorryAx` を含む結果は公開しません。画面も問題バンクと検証マニフェストのSHA-256を照合します。

日本語の説明と対数などの別解の文章自体は、独立したLean定理としての検証対象ではありません。良問性の人間による評価、任意の式の解法探索、連立・総和・差分・一般の一次分数・実数べき・階乗の追加は今後の課題です。

## 開発

```bash
python3 recurrence/scripts/generate.py
# 新しい係数・関数・選題方針を使う場合はIDを追加し、台帳もコミットする
python3 recurrence/scripts/generate.py --update-id-registry
# 別の設定で生成する場合
python3 recurrence/scripts/generate.py --config /path/to/config.json
python3 recurrence/tests/math_check.py
node --test recurrence/tests/model.test.mjs
cd recurrence/lean
lake exe cache get
lake build 2>&1 | tee ../build/lean.log
cd ../..
python3 recurrence/scripts/certify.py
```

Pagesは同じコミットの生成・Lean検証・画面確認に成功した成果物を使います。検証失敗時は公開を止めます。MathJax 4.0.0をCDNから読み込み、取得できない場合はTeXと再読み込みボタンを表示します。
